# Task 001 QA & Verification Plan (qa_plan.md)

## 1. 테스트 목적
Newtype SARL 공식 랜딩페이지가 Claude 혜택 심사 및 글로벌 방문자 관점에서 기술적 결함(깨진 레이아웃, 오탈자, 번역 누락, 빌드 에러) 없이 완벽히 동작하고 모던한 완성도를 유지하는지 검증한다.

## 2. 세부 검증 시나리오
- **시나리오 1: 빌드 및 정적 에셋 무결성 검증**
  - Vite 프로덕션 빌드 (`npm run build`) 실행 시 0 에러, 0 경고로 정상 종료되는가?
  - `dist/index.html` 및 에셋 파일들이 Cloudflare Pages에서 단독 호스팅 가능한 상대/절대 경로로 정합성을 유지하는가?
- **시나리오 2: 6개 국어 다국어 엔진 무결성 검증**
  - EN(기본), KO, VI, UZ, MN, NE 6개 언어 선택 시 모든 텍스트 키가 100% 매핑되어 `undefined`나 누락된 원문 키가 노출되지 않는가?
  - 언어 전환 시 레이아웃 텍스트 오버플로우나 줄바꿈 깨짐이 없는가?
- **시나리오 3: 뷰포트 반응형 레이아웃 스트레스 테스트**
  - 모바일(375px), 태블릿(768px), 데스크톱(1280px, 1920px)에서 수평 스크롤 버그(Overflow-X)가 발생하지 않는가?
  - 모바일 네비게이션 및 다국어 셀렉터가 터치 친화적으로 동작하는가?
- **시나리오 4: 인터랙션 및 모달 동작 검증**
  - Contact / Partner 모달 열기/닫기(ESC 키, 백드롭 클릭 포함)가 부드럽게 작동하는가?
  - 폼 유효성 검사 및 안내 메시지가 다국어에 맞게 출력되는가?
- **시나리오 5: Cloudflare Pages 배포 호환성 검증**
  - 루트 디렉토리 빌드 커맨드 `npm run build`, 출력 디렉토리 `dist` 기준 설정이 완벽한가?
